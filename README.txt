PALAK SPECIAL WEBSITE — TWO PAGE HTML/CSS/JS PROJECT

FILES
- index.html       Home / welcome page
- memories.html    Second page / personal friendship note
- style.css        Custom styling and animations
- script.js        Modal, falling sparkle effects, and wish button

HOW TO RUN
1. Extract the ZIP.
2. Keep all four files in the same folder.
3. Open index.html in Chrome.
4. Use the buttons/navigation to visit page two.

NOTE
Tailwind CSS is loaded from its CDN, so an internet connection is needed for Tailwind utility classes.
Google Fonts also load online. Custom styling and page structure are in style.css.
Edit the wording directly in index.html and memories.html if you want to make it more personal.
